# MOTIF-RACK XS — Address Map

**Authority:** *Data List* p. 62 ("Parameter Base Address"), p. 63 ("Bulk Dump
Block"), pp. 64–76 (the ten `MIDI PARAMETER CHANGE TABLE`s).

Addresses are three bytes: **High / Mid / Low**. Lower-case letters in the Mid
or Low byte are variables:

| Symbol | Meaning |
|---|---|
| `ee` | element index (Normal Voice 0–7) or drum key index (0–72) |
| `pp` | part index (0–15) |
| `nn` | program number |
| `3n` `5n` `6n` | table index carried in the low nibble of the Mid byte |

## Top-level map

| High | Mid | Block |
|---|---|---|
| `00` | `00` | System |
| `00` | `05` | Sequencer Setup |
| `00` | `20` / `21` | Master EQ / Master Effect (Voice mode) |
| `00` | `3n` / `5n` | Micro Tuning table / name |
| `00` | `6n` | Quick Setup |
| `00` | `41` | Audio In Part (mLAN) |
| `0A` | `00` | Mode Change |
| `0D` | `00` | Part Set Control for Mix Voice |
| `0E` / `0F` | `mm` | Bulk Header / Bulk Footer |
| `36` | `00`,`01`,`02`,`10`,`11`,`30` | Multi Common, Reverb, Chorus, Master EQ, Master Effect, Arp |
| `37` | `pp` | Multi Part 1–16 |
| `38` | `pp` | Multi Part 1–16, **arpeggio** |
| `39` | `41` | Audio In Part |
| `40` | `00`,`01`,`02`,`03`,`04`,`06`,`07`,`30` | Normal Voice Common, Reverb, Chorus, Ins A, Ins B, Controller+LFO, Audition, Arp |
| `41` | `ee` | Normal Voice Element — Oscillator + Amplitude + Pitch |
| `42` | `ee` | Normal Voice Element — Filter + EQ + LFO |
| `46` | `00`…`08`,`30` | Drum Voice Common and effects |
| `47` | `ee` | Drum Voice Key (`ee` = 0–72) |

## Block sizes

From the Bulk Dump Block table. The extractor in `tools/extract_parameters.py`
is validated against these: for 22 of the 23 blocks the parsed parameters span
**exactly** the documented byte count.

| Block | Address | Bytes |
|---|---|---|
| System | `00 00 00` | 52 |
| Sequencer Setup | `00 05 00` | 22 |
| Master EQ (Voice) | `00 20 00` | 20 |
| Master Effect (Voice) | `00 21 00` | 36 |
| Multi Common | `36 00 00` | 81 |
| Multi Reverb / Chorus | `36 01/02 00` | 37 / 38 |
| Multi Master EQ / Effect | `36 10/11 00` | 20 / 36 |
| Multi Arp | `36 30 00` | 13 |
| Multi Part | `37 pp 00` | 61 |
| Multi Part Arp | `38 pp 00` | 66 |
| Normal Voice Common | `40 00 00` | 82 |
| Normal Voice Reverb / Chorus | `40 01/02 00` | 37 / 38 |
| Normal Voice Insertion A / B | `40 03/04 00` | 35 / 35 |
| Normal Voice Controller + LFO | `40 06 00` | 69 |
| Normal Voice Arp | `40 30 00` | 79 |
| Element group 1 (osc/amp/pitch) | `41 ee 00` | 95 |
| Element group 2 (filter/EQ/LFO) | `42 ee 00` | 70 |
| Drum Common | `46 00 00` | 74 |
| Drum Controller | `46 08 00` | 30 |

**Documentation gap:** Sequencer Setup (`00 05 00`) is listed as a 22-byte bulk
block but the Data List publishes **no parameter table** for it. Its individual
addresses are therefore unknown from public documentation. It is not needed for
any milestone; capture it by bulk dump if it is ever required.

## Bank Select / Program Change

| Type | MSB | LSB | Programs |
|---|---|---|---|
| Normal — GM | 0 | 0 | 0–127 |
| Normal — PRE1…PRE8 | 63 | 0–7 | 0–127 each |
| Normal — USR1…USR3 | 63 | 8–10 | 0–127 each |
| Drum — Preset | 63 | 32 | 0–63 |
| Drum — User | 63 | 40 | 0–31 |
| Drum — GM | 127 | 0 | 0 |
| Mixing Voice (Multi only) | 63 | 60 | 0–15 |
| Multi (Multi only) | 63 | 68 | 0–127 |

Program numbers are 0-based on the wire. The Data List prints voice numbers
1-based; `data/voices.json` stores the **0-based** value.

## Extraction and validation

`data/parameters.json` holds 1134 parameters (918 non-reserved) across ten
scopes, generated by `tools/extract_parameters.py` and normalised by
`tools/build_parameters.py`.

Validated against the physical unit by reading every concrete address and
comparing the reply length to the documented size:

| Scope | Addresses exact | Size mismatches | Unexplained silence |
|---|---|---|---|
| System | 73 | 0 | 0 |
| Normal Voice Common | 236 | 0 | 0 |
| Normal Voice Element | 130 | 0 | 0 |
| Drum Voice Common | 186 | 0 | 0 |
| Drum Voice Key | 32 | 0 | 0 |
| **Total** | **657** | **0** | **0** |

Every silent address was either marked `reserved` or belonged to a block
inactive in the current mode. Multi (`36/37/38`) is **not yet validated** —
it requires Multi mode, which the unit would not enter over SysEx.
